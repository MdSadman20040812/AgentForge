# Visual assets

These assets make the repository readable directly on GitHub, without a third-party badge or diagram-rendering service.

- `header.svg` and `repository-guide.svg` are editable presentation artwork; their PNG exports are embedded in the README.
- The repository guide maps checked-in files; it is not a runtime validation diagram.
- Previews are browser renders or existing repository images. Captions distinguish demos, mocks, offline views and recorded research artifacts.
- Source tree inspected at `d46374aa4758e7ea1b58b1e9fe6646218c53f4d9`.
- PNG previews use an opaque background for consistent visibility in light and dark GitHub themes. Open an image to view it at full resolution.
